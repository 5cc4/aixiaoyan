# 爱小研：供 AI 阅读的项目说明

整理日期：2026-10-21。代码版本：1.7.37。

## 项目用途

供课题组成员通过浏览器协作的研究工作台，包含文献、成果、投稿进度、文件共享、组内相册、聊天、AI 助手及个人工具桌面。

## 技术结构

- 前端：原生 HTML、CSS 和 JavaScript，无前端构建步骤。
- 后端：Node.js 24+ 原生 HTTP 服务。
- 存储：SQLite（node:sqlite）；文件、账号及各类配置保存在服务器私有 data 目录。
- 依赖：imapflow、mailparser、pdf-parse、mammoth。
- AI：后端调用模型服务，支持通过独立 FreeLLMAPI 网关选择已启用的免费模型；网关服务是外部依赖，本包未包含网关源码或密钥。

## 功能边界

- 用户拥有独立账号，角色包括管理员、导师、成员；文件按全体、指定成员或仅自己可见进行权限校验。
- 共享软件与普通共享资料分区，生活照不进入共享文件列表；文献区包含课题组文献和共享文献。
- 投稿跟进按期刊聚合，状态包括投稿、送审、返修、接收、发表；邮箱配置需要另行提供授权信息。
- AI 助手支持对话项目、附件文字抽取、流式回复、等待与回答用时；仅有原文消息的旧历史不会补造耗时。
- 个人工具桌面可添加链接与四类组件，拖动顺序和内容随当前账号保存；共享软件仍使用原有共享记录与权限。

## 给分析此项目的 AI

先阅读 server.mjs、store.mjs 与 index.html，再根据需要跟进对应前端文件。请根据实际代码判断功能，勿将本说明视为已经完成的功能测试结果。

本包仅含选定的应用运行源码和说明，不含原测试目录、部署记录、服务器访问方式、依赖安装目录、真实数据库、成员资料、聊天记录、照片、邮箱凭据、模型密钥或环境配置。个别代码中的个人邮箱默认值已替换为示例值。

若要在独立环境运行：进入仓库根目录，安装 Node.js 24+，执行 npm install 和 npm start。首次运行会创建新的本地数据目录，并通过初始化口令建立管理员。AI 网关与邮箱监控需要单独配置。
