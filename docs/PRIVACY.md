# 脱敏与打包说明

整理日期：2026-10-21。应用版本：1.7.37。

## 功能保留

软件工具、共享文件、生活照相册、邮箱监控、AI 助手、聊天和个人桌面等应用功能源码保留。默认个人邮箱替换为示例地址；`package.json` 去掉未随包提供的测试目录入口，其余应用运行源码未作功能改动。

## 不包含的内容

- 实际软件安装包、工具附件、照片、头像和其他上传资料。
- 原数据库、成员名单、个人桌面内容、聊天、投稿与邮件记录。
- `.env`、API 密钥、邮箱授权码、Cookie、SSH 密钥和网关凭据。
- 初始化口令、加密密钥、预览账号、预览运行目录、截图和日志。
- 私人服务器地址、联系方式、网盘链接和部署访问资料。

## 保留的公开入口

邮箱平台的官方 IMAP 地址与官网入口、AI 厂商公开 API 地址、常用工具的官方链接保留。这些属于通用功能代码，不是私人账号、授权链接或真实单封邮件地址。

## 打包检查范围

从审核过的脱敏源码清单复制，未从预览运行目录复制账号或数据；依赖锁文件单独复制并检查。扫描已知个人及部署信息、常见密钥格式、非示例邮箱、凭据网址和本机绝对路径；核对 ZIP 文件清单及隐藏配置文件。

保留文件的说明仅适用于此源码包，不能替代以后提交新增文件时的检查。运行应用后产生的数据目录和真实配置不应提交到代码仓库。
