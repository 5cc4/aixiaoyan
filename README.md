# 爱小研 · AIXIAOYAN

面向课题组的浏览器协作工作台。采用浅紫色、轻微透明的毛玻璃界面，支持独立账号、文件共享、科研记录、投稿跟进、AI 助手和可自由排列的工具桌面。

**当前代码版本：1.7.37 · 脱敏整理日期：2026-10-21。**

**项目状态：开发中。** 当前提供核心功能源码，欢迎试用和反馈。已完成脚本语法与基础 HTTP 启动检查，尚未完成全部功能、外部 AI 服务和邮箱集成的验证。

本仓库包含应用功能源码，首次运行使用全新的空数据库，不附带原课题组资料、照片、邮件记录、模型密钥或预览账号。

## 功能

- **账号与权限**：管理员、导师、成员角色；邀请码加入；独立个人偏好。
- **研究工作台**：拖动组件、调整尺寸、编辑文字和排列导航。
- **文献与成果**：课题组文献、共享文献、发表成果及关联附件。
- **文件共享**：全组、指定成员或仅本人可见；软件资源、文献和生活照分别管理。
- **投稿跟进**：按期刊汇总投稿、送审、返修、接收、发表状态；通过邮箱内容辅助识别进度。
- **AI 助手**：对话项目、附件文字抽取、流式输出、响应计时及免费模型网关接入口。
- **课题组聊天与相册**：文字聊天、头像编辑、照片查看和轮播。
- **个人工具桌面**：链接库、自定义网址、时钟、待办、便签、倒计时及混合拖动排序。

## 技术

原生 HTML / CSS / JavaScript，Node.js 24+ 原生 HTTP 服务，SQLite（`node:sqlite`）。无需前端构建。第三方运行依赖列于 `package.json`。

## 本地运行

### 1. 安装依赖

在项目根目录打开终端：

```sh
npm install
```

### 2. 创建本地配置

将 `.env.example` 复制为 `.env`。示例默认仅监听本机 `127.0.0.1:3210`。

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

macOS / Linux：

```sh
cp .env.example .env
```

### 3. 启动

```sh
npm start
```

浏览器打开 <http://127.0.0.1:3210/>。首次启动生成 `data/setup-token.txt`，使用其中的初始化口令，在网页创建自己的管理员账号。没有预置的登录账号或密码。

如使用 pnpm，可通过 `pnpm install --frozen-lockfile` 安装锁定版本，再运行 `pnpm start`。锁文件保留本次独立预览环境的依赖解析版本。

## 配置 AI 和邮箱

- **AI**：在管理界面填写自己的模型平台配置与密钥。免费调用是否可用取决于平台政策、账号额度及服务器网络。
- **免费模型池**：使用 FreeLLMAPI 聚合时，需单独部署兼容网关，并将本地凭据文件路径填入 `FREELLMAPI_CONFIG_PATH`；此仓库不包含网关源码或凭据。
- **邮箱**：管理员在设置中配置自己的 163 邮箱及 IMAP 客户端授权码。默认个人邮箱已替换为示例地址，需自行填写有效账号。

## 部署与数据

GitHub 用于托管源码；完整网站需要 Node.js 后端运行，不能仅靠 GitHub Pages 承载。

部署时按自己的环境配置 `HOST`、`PORT`、`PUBLIC_ORIGIN` 和 `COOKIE_SECURE`。使用 HTTPS 时，应设置正确的站点来源并启用安全 Cookie。运行数据默认保存在 `data/`，备份数据时也需保留其加密密钥文件。

`.gitignore` 已忽略运行数据、依赖安装目录、真实环境配置、密钥、日志、上传资料和预览账号文件。添加新文件后仍应检查提交内容。

此源码包不包含原测试目录，已移除指向该目录的测试命令。打包阶段检查了脚本语法、文件清单和脱敏规则，未运行自动化功能测试。

## 上传到 GitHub

解压源码包，进入 `aixiaoyan` 文件夹，将里面的文件放在仓库根目录，包括 `.gitignore`、`.gitattributes` 和 `.env.example`。不要只把 ZIP 文件上传到仓库。

上传完成后，可把仓库地址及 `docs/AI_PROJECT.md` 链接提供给其他 AI；私有仓库需要对应的访问授权。
